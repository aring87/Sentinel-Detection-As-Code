# Deprecated Sentinel Detections

This directory contains older or superseded Sentinel detection rules that are no longer the preferred active versions.

## Purpose

Rules are moved here when they have been replaced by:
- better normalized naming
- improved metadata or structure
- stronger detection logic
- more current standardized rule versions

## Guidance

Files in this directory should not be treated as primary active detection content unless they are being reviewed for migration, comparison, or historical reference.

## Goal

The goal of this directory is to preserve useful history while keeping the active tactic folders clean and standardized.
