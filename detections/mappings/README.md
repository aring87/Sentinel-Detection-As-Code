# Mappings

This directory contains mapping artifacts that link detection content to security frameworks.

## Purpose

These files help track how detections align to:

- MITRE ATT&CK
- Cyber Kill Chain
- reporting and coverage reviews

## Files

- mitre-attack-mapping.csv
- cyber-kill-chain-mapping.csv

## Goal

The goal of this directory is to support coverage analysis, reporting, and prioritization of detection engineering work.
