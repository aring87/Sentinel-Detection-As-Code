# Tests

This directory contains validation support for detection engineering content.

## Purpose

Detection engineering requires more than writing logic. Content should be tested, validated, and reviewed to confirm that it works as intended and provides useful signal.

## What Belongs Here

Examples of content that may be stored here include:

- detection validation notes
- sample logs or sanitized test data
- test cases for analytics
- expected-result references
- Atomic Red Team test mappings
- screenshots or evidence from validation runs
- parser, schema, or rule-validation support artifacts

## Recommended Use

Use this directory to support:

- analytic quality checks
- pre-deployment validation
- regression testing
- tuning reviews
- engineering confidence before promotion to production
